CampusConnect

A campus event registration portal made with HTML, CSS and JavaScript. 
Students can search events, register and see how many seats are left. 
Organizers can add new events.

Live site: https://anjanaaas.github.io/campusconnect/

Features:
-Search events by name
-Register for an event (name, enrollment number and LPU email are checked)
-Seat count goes down after each registration
-Organizer form to create new events
-Data is saved in the browser, so it stays after a refresh

Files:
index.html - the page
applicablecssfile.css - styling
script.js - JavaScript
events.json - starting list of events

How to run:
Download all the files into one folder and open index.html in a browser.

Note:
There is no backend, so everything is saved only in the visitor's own browser.
